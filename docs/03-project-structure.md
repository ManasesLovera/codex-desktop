## Naming conventions

| Thing | Convention | Example |
|-------|-----------|---------|
| Rust modules/files | snake_case | `core/worktree.rs` |
| Rust types | PascalCase | `AgentRun`, `WorktreeRef` |
| Tauri commands | `snake_case`, `noun_verb` | `agent_start`, `chat_send` |
| Event topics | `domain:scope:event` | `agent:{id}:progress` |
| React components | PascalCase files | `ChatComposer.tsx` |
| Hooks | `useX` | `useChatStream` |
| Zustand stores | `useXStore` | `useWorkspaceStore` |
| TS types from Rust | imported from `lib/bindings.ts` | `import type { Project }` |
| CSS tokens | `--cdx-*` | `--cdx-color-bg-elevated` |

## Feature-slice rule

A feature lives in **both** `src/features/<name>/` (UI) and the matching Rust
modules (`commands/<name>.rs`, `core/<name>.rs`). Its spec is
`docs/specs/<name>.md`. Keep these three in sync. Shared UI goes to
`components/`; shared logic to `lib/` (TS) or `core/` (Rust).

## IPC contract sync

- Rust structs that cross the boundary derive `serde` + `ts-rs::TS`.
- `build.rs` / a `cargo test` generates `src/lib/bindings.ts`.
- The frontend imports types only from `bindings.ts`; never hand-rolls them.
- Changing a command's shape requires regenerating bindings and updating
  `docs/05-ipc-contract.md` in the same PR.

## Code conventions

- **Rust**: `cargo fmt` + `clippy -D warnings`. Errors via `thiserror`
  (`AppError`); `anyhow` only at the very edge. No `unwrap()` in non-test code
  except provably-infallible cases (document why).
- **TS**: strict mode on. No `any` (use `unknown` + zod at edges). ESLint +
  Prettier. Functional components + hooks only.
- **Comments**: explain *why*, not *what*. No comments that restate code, no
  task/PR references in code.
- **Tests** live next to code: `*.test.ts(x)` for TS, `#[cfg(test)]` modules or
  `tests/` for Rust. E2e in top-level `tests/e2e/`.
- **Imports**: absolute via `@/` alias (frontend); module paths (Rust).

## Where things go (quick reference)

| I need to… | Put it in |
|------------|-----------|
| Add a privileged operation | `src-tauri/src/commands/` + `core/` |
| Add a screen/panel | `src/features/<name>/` |
| Add a reusable button/dialog | `src/components/ui/` |
| Add a DB table | `src-tauri/migrations/` + `store/` model |
| Add a model provider call | `src-tauri/src/providers/` |
| Add an MCP integration | `src-tauri/src/mcp/` |
| Change the security policy | `src-tauri/src/harness/` + spec |
| Add a shared TS type from Rust | derive `TS`, regenerate `bindings.ts` |
